Anker

Einbürgerungstest & Leben in Deutschland

Anker bereitet Sie auf den Einbürgerungstest vor — mit allen 460 Fragen aus dem amtlichen Gesamtfragenkatalog des BAMF, inklusive der Fragen Ihres Bundeslandes.

Eine echte Prognose statt eines Fortschrittsbalkens

Anker schätzt, wie viele der 33 Prüfungsfragen Sie heute richtig hätten — und wie sicher Sie bestehen würden.

Wiederholung im richtigen Moment

Jede Frage kommt genau dann zurück, wenn Sie sie zu vergessen beginnen.

Vollständig offline

Kein Konto, keine Anmeldung, keine Daten an Dritte. Anker funktioniert ohne Internet.

Hilfe & Kontakt

Fragen, Fehler in einer Frage entdeckt, oder ein Problem mit einem Kauf? Schreiben Sie an emperorduke5@gmail.com — Sie bekommen normalerweise innerhalb von zwei Werktagen eine Antwort.

  • Kauf wiederherstellen: Einstellungen → „Kauf wiederherstellen“.
  • Bundesland ändern: Einstellungen → Bundesland → „Ändern“.
  • Fortschritt zurücksetzen: Einstellungen → „Fortschritt zurücksetzen“.
